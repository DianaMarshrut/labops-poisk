# labops-poisk — Поиск кандидатов: профиль, запросы, ссылки

Капсула строит профиль кандидата, составляет булевы поисковые запросы
и готовит ссылки на hh.ru, SuperJob, Habr Career и Зарплата.ру — по тексту вакансии
или описанию роли. Поиск ведёшь сам в своём работодательском аккаунте.

**Что получаешь:**
- Профиль кандидата: обязательно / желательно / стоп-факторы.
- Булевы запросы: широкий и точный вариант под вакансию.
- Готовые ссылки с фильтрами на четыре площадки.
- Советы — где ещё искать.

## Как поставить

### Claude Code

```
/plugin marketplace add DianaMarshrut/labops-poisk
/plugin install poisk@labopsai-poisk
```

Напиши: **«Поиск»**.

### Claude (claude.ai, приложение)

1. Customize → Plugins → Add marketplace.
2. Вставь: `DianaMarshrut/labops-poisk`
3. Установи плагин «poisk».
4. Напиши: **«Поиск»**.

### Codex

```
codex plugin marketplace add DianaMarshrut/labops-poisk
```

Через `/plugins` → Install → новая сессия → напиши: **«Поиск»**.

### ChatGPT (через проект)

1. Создай проект «Поиск кандидатов» в ChatGPT.
2. Загрузи файл `chat-instruction.md` в файлы проекта.
3. Напиши: **«Поиск»**.

## Откуда берём данные

| Вариант | Как передать |
|---|---|
| Текст вакансии файлом | Загрузи `.txt`, `.docx`, `.pdf`, `.xlsx` или `.csv` в чат |
| Своими словами | Напиши должность, задачи, требования, город |

## Ограничения

- Капсула не открывает площадки и не собирает резюме — поиск ведёшь сам.
- Поисковые ссылки составлены по общей структуре URL — параметры могут меняться [проверить].
- Капсула не получает доступ к базам резюме и не собирает контакты кандидатов.
- Резюме — персональные данные; работаешь с ними в рамках своего работодательского аккаунта.
- Если загружаешь файл с кандидатами: замени ФИО на Кандидат 1, Кандидат 2 и т.д.,
  убери телефоны, email и паспортные данные.
- Операторы булевого поиска AND/OR/NOT: поддержка зависит от площадки [проверить в справке].
  Запасной вариант — ключевые слова через запятую.
- 1С: выгрузи отчёт из 1С в Excel и загрузи файлом в чат.

## Команды

| Команда | Что делает |
|---|---|
| `Поиск` | Начать: задать первый вопрос об источнике данных |
| `Обнови запросы` | Перестроить булевы запросы с новыми требованиями |
| `Добавь площадку [название]` | Добавить ссылку для новой площадки |
